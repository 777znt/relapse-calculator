# Calculator (iOS-style curved buttons)

Pure static calculator with circular iOS buttons.

## Special Feature
Press **=** → typing animation of the lyrics plays + the song from `relapse/song.mp4` starts.

Sequence:
1. ako..
2. (clear)
3. ako... ako ang bagyooooooo,   (holds 4s)
4. kulimlim ang langit sa inyong dalawa.
5. bulong ko sa hangin sana di kayo masaya, sa tibay ng bahay tinitirahan nyo, tatangayin ko bawat yero

## How to use
1. Unzip
2. Open `index.html` in any browser
3. Optional: replace `relapse/song.mp4` with your own track (.mp4)

No server needed.
